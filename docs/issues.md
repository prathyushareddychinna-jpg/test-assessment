# Issues / Defect Log

Only issues reproduced during the assessment run should be recorded as confirmed defects.

For each confirmed issue, record:

- Defect ID
- Title
- Priority / severity
- Environment
- Preconditions
- Steps to reproduce
- Expected result
- Actual result
- Evidence
- Impact
- Reproduction date/time

## Exploratory areas

The following areas are useful candidates for focused exploratory testing:

- Empty-cart checkout behaviour
- Credit-card input validation
- Duplicate product handling in the cart
- Invalid or unknown URL behaviour
- Registration validation
- Login validation
- Cart totals and removal behaviour

Populate the confirmed defect section only after reproducing an issue and capturing evidence.
